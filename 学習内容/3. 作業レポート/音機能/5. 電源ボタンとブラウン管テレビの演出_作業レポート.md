# 作業レポート：電源ボタンとブラウン管テレビの演出  261107

サイドバーの電源ボタンで、背景を切り替えるようにした。オンで背景画像、オフでビジュアライザーになる。切り替えには、ブラウン管テレビが点く・消える時のような演出を付けた。PR #40 でマージ済み。

<br>

---

## 1. 最初にやりたかったこと：電源ボタンでブラウザを閉じる

### 1-1. 結論：ページの側からは、タブをほぼ閉じられない

- ページの JS には、タブを閉じる命令（`window.close()`）がある。
- ただし、ブラウザが閉じるのを許すのは、次のどちらかの時だけ。
  - JS で開いたタブ（ビー玉から開いたビジュアライザーのタブなど）
  - そのタブで、まだ1ページしか見ていない時（ブラウザによる）
- このアプリは「憶」「音」と移るたびに履歴が増えるので、すぐにこの条件から外れる。
- 閉じられない時、ブラウザは命令を黙って無視する。

<br>

### 1-2. ブラウザがこう決めている理由

- 開いたサイトが勝手にタブを閉じられると、使う人が困るため。
- どのサイトでも同じ決まりである。タブを閉じられるのは、使う人自身（×ボタンや Cmd + W）だけ。

<br>

### 1-3. 方針を変えた

- 「タブを閉じる」のはやめて、**電源ボタンを背景の切り替えに使う**ことにした。
  - オン：背景画像
  - オフ：アンビエント（ビジュアライザー）
- 切り替えの演出は、ブラウン管テレビのオン・オフのようにする。
- 前回付けた壁紙のボタンは、役目が電源ボタンに移ったので外した。

<br>

## 2. ブラウン管テレビの演出

### 2-1. 動き

| | 流れ | 長さ |
|---|---|---|
| オフ | 背景画像が上下からつぶれて、白く光る横線になる → 横からも縮んで点になる → 消える → ビジュアライザーが、3秒かけてゆっくり明るくなる | 0.8秒 + 3秒 |
| オン | まわりが真っ暗になる → 真ん中に白い点が灯る → 横に伸びて線になる → 上下に広がって、背景画像が映る → 少し明るすぎた画面が落ち着く | 0.9秒 |

<br>

### 2-2. 動くのは、背景画像の層だけ

- サイドバーやメモのパネルは、そのまま残る。
- テレビの画面が背景で、アプリはその手前にある、という見せ方にした。
- 前回、背景画像を別の層（`.background::before`）に分けておいたので、その層だけを動かせた。

<br>

### 2-3. 仕組み

- CSS のアニメーション（`@keyframes crt-off` / `crt-on`）で、背景画像の層を変形させている。
  - `transform: scale(横, 縦)`：縦だけ 0.004 倍にすると、細い横線になる。横も 0.004 倍にすると、点になる。
  - `filter: brightness(6〜8) saturate(0)`：線や点の時は、色を抜いて明るくして、白く光らせる。
- 電源ボタンを押した時だけ、`<html>` に `crt-off` / `crt-on` の目印を付けて、演出を流す。
  - ページを開いた時や、ページを移った時は、目印が付かないので演出は流れない。
  - 演出が終わったら（`animationend`）、目印を外す。
- 演出の途中でもう一度押された時は、前の演出をやめて、新しい方を最初から流す。
  - 目印を外してすぐ付け直すだけだと、ブラウザが「変わっていない」とみなして、2回目が動かない。
  - そこで、外したことを一度ブラウザに反映させてから（`void html.offsetWidth`）付け直している。

<br>

## 3. 演出中に、後ろが見えてしまう問題

### 3-1. オフの時

- **起きたこと**：背景画像が縮んでいく間に、空いたところから、もうビジュアライザーが見えていた。
- **原因**：ビジュアライザーは、背景画像のすぐ後ろにあり、オフを押した瞬間から見える状態になっていたため。
- **対応**
  - 演出の間だけ、ビジュアライザーを透明にして隠した。
  - 演出が終わって目印が外れると、3秒かけてゆっくり明るくなる（明転）。この3秒は、ページを開いた時にふわっと出る速さと同じ。

<br>

### 3-2. オンの時

- オフに合わせて、オンの演出の間も、ビジュアライザーを隠した。
- ただし、オンを押した時点で、背景を暗くする目印（`html.ambient`）はもう外れている。そのままだと、まわりが白くなってしまう。
- そこで、オンの演出の間だけ、暗い色を別に付けるようにした。

<br>

---

## 4. 確認したこと

- オン・オフの両方で、演出の途中の状態を0.2〜0.3秒ごとに記録して、次のことを確かめた。
  - つぶれる → 線 → 点、点 → 線 → 広がる、の順に動くこと。
  - 演出の間は、ビジュアライザーが隠れていること。
  - オフの後に、約3.5秒かけてビジュアライザーが明るくなること。
  - オンの間は、まわりが暗い色になっていること。
- オフの途中で演出を止めて画面を撮り、白い横線が出ていることを確かめた。
- コンソールにエラーが無いこと。

**気づいたこと**
- 確認の途中で、同じブラウザのタブを手でも操作していたため、1回目の記録が混ざった。
- 1回で状態を記録しきる形に変えて、やり直した。
