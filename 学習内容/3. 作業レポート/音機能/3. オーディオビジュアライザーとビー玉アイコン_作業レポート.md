## 1. 前段の話し合い

### 1-1. WebXR 化の予定

将来、このアプリを WebXR にしたい、という方針を共有した。

- 「記憶の宮殿」は、空間に物を置いて覚える記憶術なので、XR と相性が良い。
- 今の見た目や演出（CSS のフワッと、ジニー、Webamp の見た目）は、VR の中では表示されないので、作り直しになる。
- データ（メモ、画像、天気、日付）と Rails 側は使い回せる。
- そのため、今後のテーブル設計では、次の点に気をつける。
  - 「中身」と「配置」を分けて保存する。
  - 位置を、画面のピクセルではなく、割合で保存する。

<br>

### 1-2. Webamp の使い方とビジュアライザー

- Webamp のプレイリストの各ボタン（ADD・REM・SEL・MISC・LIST OPTS）の役割を整理した。
- Webamp のビジュアライザーは2種類あり、どちらも今のアプリで使える。
  - メインウィンドウの小さい表示：スペクトラムアナライザー、オシロスコープ、オフ
  - Milkdrop
- 最初は「Milkdrop は追加の設定が無いと使えない」と答えたが、間違いだった。今の Webamp（2系）には、最初から Milkdrop のプリセットを読み込む仕組みが入っていた。
- Milkdrop は動きが激しく、アンビエントな音楽に合わない。そこで、プレステ2のメニューのような、穏やかなビジュアライザーを自作することにした。

<br>

## 2. ビジュアライザーの試作

`public/visualizer/index.html`（three.js で作った 3D の空間）。最初は `tmp/mock` で試作し、後で `public` に移した。

### 2-1. 最終的な見た目と動き

| 部品 | 見た目と動き |
|---|---|
| 空間 | 青紫の暗い空間を、カメラがゆっくり前へ進む |
| 光る塵 | はるか遠くの暗闇からぼんやり現れて、ゆっくり近づいてくる |
| 大きくぼやけた玉 | 少しだけ漂う（数は控えめ） |
| 塔のブロック | ゆっくり回りながら、上下にぷかぷか浮かぶ。ブロックがランダムに、ゆっくり増えたり減ったりする |
| ブロックの質感 | ほんのり薄いメタリック。中は、ほんのり均一に白く濁る |
| ブロックの枠 | くっきりした線は無い。中心の光を向いた側の枠が、にじんでブレたように光る |
| 中心の光 | 青白い光が、呼吸するように明るさと大きさを変える |
| 開いた時 | 暗闇から3秒かけて、ふわっと浮かび上がる |

<br>

### 2-2. 音への反応

- 音楽ファイルを選ぶ（ドラッグでも可）か、デモ音を流すと反応する。
- 音を、低音・中音・高音の3つに分けて読み取る（Web Audio API）。
- **激しくならない工夫**：読み取った値をそのまま使わず、前の値から少しずつ近づける。曲が急に盛り上がっても、映像はふわっと変わるだけになる。
- 「反応の強さ」と「ゆっくりさ」は、つまみで変えられる。

<br>

### 2-3. 試して、やめたもの

| 試したもの | やめた理由 |
|---|---|
| 背景の、ぼやけた巨大なブロック群 | 中心の光とぶつかって、全体が見づらくなった |
| 塔の後ろの影 | 床も壁も無い空間では、影が落ちる先が無く、ほぼ見えなかった |
| ブロックの中心だけの霞 | 中心が点のように見えた。ブロック全体を均一に濁らせる形に変えた |
| くっきりした枠線 | 目立ちすぎた。濁りを縁に向かって明るくするグラデーションで、枠線の代わりにした |

<br>

### 2-4. 途中で見つけた問題

- **中心の光の縁が、輪になって見えた**
  - 原因：3D の画面を透明にして、CSS の背景を透かせていたこと。光を足し合わせる描き方と相性が悪かった。
  - 対応：背景のグラデーションも、3D の側で描くようにした。
- **塔の回転が止まっていた**
  - 原因：「回っている塔をぷかぷかさせて」を、「回転をやめて、ぷかぷかにする」と読み違えていた。
  - 対応：回転を戻した。

<br>

### 2-5. デモ音

- ファイルが無くても試せるように、ゆっくり揺れる和音を、その場で鳴らすデモ音を作った。
- 気に入ったので、WAV に書き出すスクリプト `script/make_demo_pad.py` を作った。
- WAV（約8MB）は、Git に入れない（.gitignore に追加）。スクリプトがあれば、いつでも作り直せるため。

## 3. 「音」の画面のビー玉のアイコン

置き場所は、Milkdrop の中には出せない（Milkdrop は専用の形式しか映せない）。そこで、「音」の画面にアイコンを置き、クリックで別タブを開く形にした。

### 3-1. 見た目

- デザインは、銀河 → 昔のビー玉 → プラズマボール、と変えていった。
- 最終形は、プラズマボールのように、青白い光の筋がウネウネとゆっくり動く玉。
  - ところどころピンクが差す。
  - 外縁は薄く透けていて、透明感がある。
- **仕組み**（`app/javascript/marble.js`）
  - ボタンの中に `<canvas>` を置き、玉の点1つ1つの色を GPU で計算している（WebGL のシェーダー）。
  - 雲のようなムラ（ノイズ）の「ちょうど 0 になる所」だけを光らせると、うねった光の筋になる。そのムラ自体をゆっくりゆがめることで、ウネウネさせている。
  - うねり具合（ゆがめる強さ）は 0.20 に決めた。
- 見出し「音楽」の右隣に、文字と同じ高さにそろえて置いた。「音楽」と一緒に、フワッと出し入れする。

<br>

### 3-2. ドラッグとクリック

- **ドラッグ**
  - マウスに少し遅れて、ヌラ〜っと付いてくる。
  - 速く動かすと、進む向きにほんの少し伸びる。
  - 動かせるのは、右側の画面の中だけ。
- **クリック**
  - `/visualizer/` を別タブで開く。
  - ドラッグして離した時は開かない。4px 以上動いたら「ドラッグした」とみなして区別している。
  - 別タブは `noopener` を付けて開く。開いたタブから、元のタブを操作できないようにするため。

<br>

### 3-3. 制約

- 別タブのビジュアライザーは、Webamp で流している曲には反応しない。ブラウザでは、別のタブの音を読み取れないため。
- タブの切り替わり自体は、ふわんとさせられない（ブラウザが行うため）。代わりに、開いた先を暗闇からふわっと出している。
- ビー玉を動かした位置は、「音」を開き直すと元に戻る。
