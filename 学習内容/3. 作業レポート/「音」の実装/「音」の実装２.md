# 音の実装２  260926

対象：`~/Desktop/portfolio_latests/MemoApp`（Rails 8.1 + importmap）

## 決まった仕様

- **「憶」「時」に切り替えても音楽は止まらない**：バックグラウンドで流れ続ける
- **Webampで再生したら、今のBGMは自動で止める**：今のBGMは、トップ画面でEnterキーを押すと鳴る `bgm.wav`
- **Webampのウィンドウは「音」のときだけ表示**：「憶」「時」では表示しない
- **Webampのファイルは、初めて「音」を開いたときだけ読み込む**
- **ローカルサーバーだけで使う**：曲の権利は問題なし

---

## 今のMemoAppの作り

- 画面は `top#index` の**1ページだけ**です。
- サイドバーの「憶」「時」「音」は、レイアウト（`application.html.erb`）にある `<li class="item-boxes">` です。
  - これらはリンクではありません。クリックすると、JavaScriptがパネルの `show` クラスを付けたり外したりして、開閉しています。
  - 「憶」の開閉は、`top.js` の④が担当しています。
- BGMは、`top/index.html.erb` の最後にある `<audio id="bgm" src="/bgm.wav" loop>` です。
  - `top.js` の②で、**最初のEnterキー1回だけ**（`once: true`）`bgm.play()` しています。
  - この `<audio>` 要素は、`window.js` の `getRefs()` から `bgm` という名前で取れます。

## 設計案

### 1. ページ移動がないので、音楽は勝手に止まらない

MemoAppでは、「音」から「憶」に切り替えても、同じページの中で表示を変えているだけです。Webampを一度 `<body>` に表示すれば、そのまま残り続けます。

そのため、**`data-turbo-permanent` のような特別な工夫は不要**です。

### 2. 表示は「音」のときだけ（隠しても再生は続く）

Webampは消さずに（`dispose()` しない）、**見た目だけ隠します**。

| クリック | Webamp |
|---|---|
| 「音」 | 表示する |
| 「憶」「時」 | `display: none` で隠す。再生は続く |

- 「音」のクリック：新しく作る `sound.js` が担当します。
- 「憶」のクリック：`top.js` の④に「Webampを隠す」処理を足します。
- 「時」のクリック：これから作る「時」の処理に同じものを入れます。
- 「音」を押したときに記憶パネルを閉じるかどうかも、あわせて決めます。

### 3. 読み込むのは初めて「音」を開いたときだけ

`sound.js` の中で、「音」のクリック時に `import("webamp")` を使います。こう書くと、ファイルは**最初に「音」を開いた瞬間だけ**読み込まれます。

2回目以降は、読み込み済みのWebampを表示し直すだけです。

### 4. Webampで再生したら、Enterキーの BGM を止める

Webampには「再生が始まったとき」専用のイベントがありません。代わりに次の2つを組み合わせます。

- `onTrackDidChange`：曲の読み込みが始まったときに呼ばれます。
- `getMediaStatus() === "PLAYING"`：今再生中かどうかを確認できます。

どちらかで再生を検知したら、`bgm.pause()` を呼びます。

ただし、「停止中の同じ曲をもう一度再生した」ときに `onTrackDidChange` が呼ばれるかどうかは、ドキュメントからは判断できませんでした。実装するときに動かして確認が必要です。

### 5. ファイルの置き方（importmapの流儀に合わせる）

| ファイル | 役割 |
|---|---|
| `vendor/javascript/webamp.js` | Webampのファイル（Milkdrop入りの `webamp.butterchurn-bundle.min.mjs`）をダウンロードして置く |
| `config/importmap.rb` | `pin "webamp"` を追加 |
| `app/javascript/sound.js`（新規） | 「音」の担当。読み込み・表示・非表示・BGM停止 |
| `app/javascript/application.js` | `import "sound"` を追加 |
| `public/` | Webampで流すmp3を置く（`bgm.wav` と同じ場所） |

### 構成のイメージ

```
<body>
  サイドバー（憶・時・音）      ← クリックでパネルを切り替えるだけ。ページ移動なし
  main_content
    └─ top/index の中身（記憶パネルなど）
         └─ <audio id="bgm">  ← Enterキーで鳴るBGM。Webamp再生時に止める
  #webamp                      ← 初めて「音」を押したときに追加される
                                  「音」以外では隠すだけなので鳴り続ける
</body>
```

## 実装のときに気をつけること

1. **ヘッダーの `<h1>` 3つが、同じ `id="header_title"` になっている**（記憶・カレンダー・音）
   - `getElementById` は最初の1つ（「記憶」）しか返しません。
   - 「音」の見出しを切り替えるときに困るので、`id` を分けるのがよいです。
2. **Enterキーの判定が、BGMが鳴る前の1回だけ**（`once: true`）
   - Webampで止めたあとに、Enterキーでもう一度BGMを鳴らしたい場合は、この部分を変える必要があります。
3. **隠している間のMilkdrop**
   - 隠している間、Milkdropの描画も止めるか、隠れたまま動かしておくか、という点があります。
   - パソコンへの負荷を見て決めれば大丈夫です。

## まだ決めていないこと

  - 今の `once: true` のままなら、2回目以降のEnterでは何も起きません。この動きでよければ、決める必要はありません。
