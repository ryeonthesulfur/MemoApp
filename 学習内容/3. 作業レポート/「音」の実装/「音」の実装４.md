## 2. 決まっている仕様

## 5. 仕様を実現する仕組み

| 対象 | 何もしないと | 対処 |
|---|---|---|
| **Webampの音** | 止まらない。内部の `<audio>` は画面に置かれていない（ソースで確認済み） | 不要 |
| **Webampのウィンドウ** | ページを移ると消える。`#webamp` が `<body>` の直下にあるので、`<body>` ごと捨てられる | 消えるのは仕様どおりなので、そのままでよい。「音」に戻ったときに付け直す（下の「ウィンドウを戻す」） |
| **BGM** | ページを移ると止まる。画面から取り除かれた `<audio>` は、ブラウザが自動で一時停止する | `<audio id="bgm">` をやめて、`window.bgm = new Audio("/bgm.wav")` のようにJSだけで作る |

### ウィンドウを戻す

Webampは、同じインスタンスを2回表示できない（`Cannot render a Webamp instance twice` というエラーになる）。そこで、次のようにする。

1. 初めて「音」を開いたときに、Webampを作って表示する。
2. できた `#webamp` の要素を、JSの変数で覚えておく。
3. 「憶」「時」に移ると、Turboが `<body>` を入れ替えるので、ウィンドウは消える。
   - 要素は画面から外れるだけで、変数の中に残っている。
4. 「音」に戻ったら、覚えておいた要素を `<body>` に付け直す。

画面から外した要素を付け直してきちんと動くかは、**実験で確認が必要**。

### BGMを止める・鳴らし直す

- **止める**
  - Webampには「再生が始まったとき」専用のイベントがない。
  - そこで、`onTrackDidChange`（曲の読み込みが始まったとき）と `getMediaStatus() === "PLAYING"`（今再生中か）を組み合わせて再生を検知し、`bgm.pause()` を呼ぶ。
  - 「停止中の同じ曲をもう一度再生した」ときに `onTrackDidChange` が呼ばれるかは、ドキュメントからは判断できない。**実験で確認が必要**。
- **鳴らし直す**
  - Enterキーを押すたびに `bgm.play()` を呼ぶ。今の `top.js` の② にある `once: true` は外す。
  - すでに鳴っているときに `play()` を呼んでも、何も起きない（最初から再生し直すことはない）。
- **Enterキーの設定は、画面全体の読み込みで1回だけ登録する**
  - `turbo:load` の中で登録すると、ページを移るたびに同じ設定が増えていく。
  - そのため、`turbo:load` の外に書く。

## 6. JSで直すこと

1. 各ファイルに「要素が無ければ `return`」を入れる
   - 「音」のページには「憶」の要素が無いので、今のままだとエラーになる。
2. `document` に付けている設定を1回だけ登録する形にする
   - `select.js` の⑤などが該当する。今のままだと、ページを移るたびに二重になる。
3. `top.js` の④（「憶」クリックでパネルを開閉する処理）を見直す
   - サイドバーがリンクになるので、この処理の役割が変わる。
4. `top.js` の②（Enterキーで鳴るBGM）を作り直す
   - `window.bgm = new Audio(...)` にする。
   - `once: true` を外す。
   - `turbo:load` の外で1回だけ登録する。
