# 分割代入で名前を変えて受け取る書き方、解説  260913

`const { 元の名前: 新しい名前 } = オブジェクト;`という書き方について。`getRefs()`を使う場面で今後も出てくるので、まとめておく。

---

## 1. 困る場面(具体例)

`window.js`の`getRefs()`は、こういうオブジェクトを返す。

```javascript
{
  folder_panel: document.getElementById('folder_columns_container'),
  ...
}
```

キー名は`folder_panel`。ところが、あるファイルの中では、もうずっと前から`folder_columns_container`という名前で同じ要素を使っている(何十行にも渡って登場する)。

普通に分割代入すると、こうなる。

```javascript
const { folder_panel } = getRefs();
```

これだと変数名は`folder_panel`になってしまう。ファイル中に既にある`folder_columns_container`という名前の記述を、全部`folder_panel`に書き換えないといけなくなる。

---

## 2. 解決策: 名前を変えて受け取る

分割代入には、「オブジェクトの中の名前」と「こっちで使いたい変数名」を別々に指定できる書き方がある。

```javascript
const { folder_panel: folder_columns_container } = getRefs();
```

`:`の左側が「オブジェクトの中の、元の名前」、右側が「これから使いたい、新しい変数名」。

これで、`getRefs()`(オブジェクトのキーは`folder_panel`のまま)を使いつつ、ファイル内では今まで通り`folder_columns_container`という名前で書き続けられる。

---

## 3. 小さい例で確認

```javascript
const obj = { a: 1, b: 2 };

const { a } = obj;
console.log(a); // 1 (そのままの名前)

const { a: x } = obj;
console.log(x); // 1 (中身は同じだが、変数名はxになっている)
// console.log(a); ← これはエラー。aという名前では受け取っていないため
```

`a: x`は「`obj.a`の値を、`x`という名前の変数に入れる」という意味。

---

## 4. 実際に使った箇所

`folder_columns.js`で、この書き方を使った。

**Before**

```javascript
const { icon_container } = getRefs();
const folder_columns_container = document.getElementById('folder_columns_container');
```

**After**

```javascript
const { icon_container, folder_panel: folder_columns_container } = getRefs();
```

`document.getElementById(...)`を直接書く代わりに`getRefs()`を使うようにしつつ、キー名(`folder_panel`)とファイル内で使いたい変数名(`folder_columns_container`)が違うので、名前を変えて受け取る書き方で対応した。

---

## 5. いつ使うか(判断基準)

- `getRefs()`のキー名と、そのファイルで使いたい変数名が**同じ**なら → 普通の分割代入でいい(`const { memo_panel } = getRefs();`)
- キー名と、そのファイルで**既に使われてる**変数名が**違う**なら → 名前を変えて受け取る書き方を使う(ファイル内の既存コードを書き換えずに済む)
