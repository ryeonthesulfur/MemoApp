# 2026-07-21 「自分で作った変数」と「ブラウザ標準機能」の違い

`memo_saving.js`の`new_memo.dataset.memoId = savedMemo.id;`について、「`memoId`は`window.js`に書いてないのに、なぜ使えるのか」という疑問から整理した内容です。

---

## 結論

JSに出てくる「名前」には、大きく分けて2種類あります。

| 種類 | 例 | 他ファイルで使うには |
|---|---|---|
| ① 自分で作った変数 | `panel`、`icon_container`、`memo_panel` | `window.js`(`getRefs()`)に用意する必要がある |
| ② ブラウザが標準で持ってる機能 | `.dataset`、`.textContent`、`.classList`、`.style` | 何もしなくても、どの要素からでも最初から使える |

`.dataset.memoId`は②に当たるので、`window.js`に用意する必要がありませんでした。

---

## ①「自分で作った変数」とは

```javascript
const panel = document.getElementById('main_panel');
```

これは、「`#main_panel`という要素を探してきて、`panel`という**自分で決めた名前**を付けて覚えておく」という行為です。`panel`という名前は、このコードを書いた人が決めたものなので、他のファイルは何もしなければ`panel`の存在を知りません。

複数のファイルから同じ`panel`を使いたい場合、`window.js`の`getRefs()`にまとめて、そこ経由で共有する必要がありました。これが今まで何度も出てきた「ファイルを跨ぐと変数が見えない」問題への対応です。

---

## ②「ブラウザが標準で持ってる機能」とは

```javascript
const new_memo = document.createElement('div');
new_memo.dataset.memoId = savedMemo.id;
new_memo.textContent = '何か';
new_memo.classList.add('folder-icon');
```

`document.createElement('div')`で要素を作った瞬間から、その要素には**ブラウザが最初から用意してくれてる機能**(`.dataset`、`.textContent`、`.classList`、`.style`など)が、**何もしなくても付いています。**

これは、`panel`のように「探してきて名前を付ける」ものではなく、「**JavaScript(DOM)という仕組みそのものが、全部の要素に標準装備してる道具**」です。`import`も`window.js`への追加も一切不要で、どのファイルの、どんな要素に対しても、いつでも使えます。

---

## 図で整理

```
① 自分で作った変数(panel など)
   │
   │ document.getElementById(...) で「探してきて」「名前を付ける」
   ▼
  自分の書いたコードの中だけに存在
   │
   │ 他のファイルでも使いたい
   ▼
  window.js の getRefs() にまとめて、共有する必要がある


② ブラウザ標準機能(.dataset など)
   │
   │ 要素を作った瞬間から、ブラウザが自動で持たせてくれている
   ▼
  どのファイルの、どの要素からでも、最初から使える
  (共有の仕組みを用意する必要が無い)
```

---

## 今回の具体例

```javascript
new_memo.dataset.memoId = savedMemo.id;
```

- `new_memo`: 自分で`document.createElement('div')`して作った要素(自作)
- `.dataset`: `new_memo`が最初から持ってる、ブラウザ標準の機能(共有の仕組み不要)
- `.memoId`: `.dataset`の中で、`data-memo-id`というHTML属性に対応する決まった名前(変数ではなく、命名ルールの一部)
- `savedMemo.id`: サーバーから返ってきたJSONを変換して得た、既に取得済みの値

`memoId`という文字だけを見ると「どこかで定義されてる変数」に見えてしまいますが、実際は「`.dataset`というブラウザ標準機能の中の、決まった項目名」なので、`window.js`で用意する対象には当てはまりません。
